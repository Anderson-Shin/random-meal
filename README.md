# What Should I Eat HK?

A multilingual, static-first Hong Kong restaurant decision website that helps people quickly choose where to eat.

## Current Status

**v0.1.0 - Documentation Setup**

The project governance, product rules, roadmap, and future restaurant data schema are defined. Website code and restaurant data have not been created yet.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- JSON
- Cloudflare Pages

## Development Philosophy

The project stays static-first, beginner-editable, SEO-friendly, low-cost, and maintainable. Simple, working solutions take priority over fancy or premature features. The MVP uses no framework, build tool, backend, paid API, AI, Google Maps, login, or user accounts.

## Future MVP Direction

The next version will establish the static website skeleton, then add manually curated restaurant data, simple filters, a random picker, a roulette-style decision tool, and English, Traditional Chinese, and Simplified Chinese UI.

See [docs/ROADMAP.md](docs/ROADMAP.md) for the full version plan.
