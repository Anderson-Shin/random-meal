# Domain Setup Guide

## Current Placeholder

The project currently uses:

```text
https://example.com
```

This appears in:

- `sitemap.xml`
- `robots.txt`
- District page canonical URLs
- District page Open Graph URLs

The placeholder is intentional until a production domain is connected.

## After Domain Is Chosen

Search the project for:

```text
https://example.com
```

Replace every occurrence with the real domain.

Example:

```text
https://whatshouldieathk.com
```

## Files to Check

- `sitemap.xml`
- `robots.txt`
- `regions/quarry-bay.html`
- `regions/central.html`
- `regions/kwun-tong.html`

After replacement, confirm that all URLs use HTTPS, contain the intended hostname, and load successfully.

## Important Rule

Do not submit the sitemap to Google Search Console until the placeholder domain has been replaced.
